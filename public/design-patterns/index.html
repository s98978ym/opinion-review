Pattern A

テキスト + リッチカード（現行改善版）

現行デザインをベースに改善。テキストメッセージで丁寧に内容を説明し、その下にリッチカードで視覚的に記事を紹介。

親しみやすい文体 情報量多め 既存踏襲
Pattern B

フルビジュアル リッチメッセージ

テキストを最小限に抑え、ビジュアルで訴求。note更新をブランディングされたカードで紹介。記事内容が一目で伝わる構成。

視覚インパクト ブランド統一 シンプル導線
Pattern C

マガジン型 Flex Message

横分割レイアウトで記事とスピーカーを同時に紹介。記事のポイントを箇条書きで表示し、デュアルCTAで行動を促進。

構造的レイアウト ポイント訴求 複数CTA Quick Reply
